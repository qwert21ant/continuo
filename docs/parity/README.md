# Parity dumps

The files in this directory (`blocks-1.7.10.txt`, `blocks-1.21.11.txt`, `golden-1.7.10.txt`, `golden-1.21.11.txt`) are dumps of the fixture world described in `fixture-layout.md`, one canonical `index\tid\tstateKey\tdata` line per position. They are **generated by a human running the fixture in a real client of each version and pressing the dump keybind** — never written or edited by hand. Hand-editing any of these files defeats their entire purpose, since `BlockParityTest` exists to prove what the two real adapters actually report, not what someone typed.
